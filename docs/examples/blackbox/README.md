# Controlled localhost graph example

These exports were generated by the actual BlackBox workflow against the controlled loopback fixture in `tools/verify_local_workflow.py`. The server is no longer running. No public target/provider was scanned. External references are recorded but not requested.

The fixture produced **22 URLs, 17 observed URLs, 6 API candidates, 90 nodes and 179 relationships**. Counts include the explicitly labeled external reference. Exit status is partial because direct active tools remain restricted; the graph records their native engines and limitations. JS inference and observed HTTP are separate request evidence.
